VENDE TU CUENTA — paquete para publicar

Archivos:
- index.html: sitio web actual con botón RGB, panel lateral, perfiles de demostración y ayuda por correo.
- firebase-app.js: integración de Firebase preparada; requiere configuración propia.
- firestore.rules: reglas iniciales de Firestore; revisarlas antes de producción.
- vercel.json: encabezados de seguridad básicos para el hosting Vercel.
- DEPLOYAR_Y_PAGOS.md: pasos detallados para publicar, configurar Google y preparar pagos.
- CONFIGURACION_FIREBASE.txt: guía Firebase resumida.

IMPORTANTE: el checkout actual es de demostración. No cobra ni confirma dinero real. La autenticación Firebase requiere configuración antes de funcionar. El paquete no implementa aún backend de pagos, webhooks ni custodia de fondos.

Empieza leyendo DEPLOYAR_Y_PAGOS.md.
